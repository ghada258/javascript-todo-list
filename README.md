# My Tasks – To-Do List App

## 📌 About The Project

**My Tasks** is a simple and interactive To-Do List application built with HTML, Tailwind CSS, and JavaScript.

It helps users organize their daily tasks by adding new tasks, editing existing ones, marking tasks as completed, and deleting tasks. The application uses Local Storage to save tasks in the browser, so they remain available even after refreshing the page or reopening the browser.

## ✨ Features

- **Add Tasks:** Create new tasks with a name and due date.
- **Edit Tasks:** Update existing task names and dates.
- **Delete Tasks:** Remove tasks from the list.
- **Mark as Completed:** Toggle tasks between completed and incomplete.
- **Local Storage:** Save tasks in the browser to preserve data between sessions.
- **Interactive Popup:** Use a popup form to add or edit tasks.
- **Task Status Indicators:** Display completed tasks with a green background and strikethrough text.
- **Dynamic Rendering:** Update the task list automatically after each operation.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES6+)
- Local Storage API
- Font Awesome

## 🚀 Getting Started

### Prerequisites

A modern web browser is all you need to run this project.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ghada258/javascript-todo-list.git
   ```

2. Navigate to the project directory:

   ```bash
   cd javascript-todo-list
   ```

3. Open `index.html` in your browser.

No additional installation or build process is required.

## 💡 Key JavaScript Concepts

This project demonstrates practical use of:

- **Arrays and Objects:** Store and manage task data.
- **Array Methods:** Use `map()`, `find()`, and `filter()` to manipulate tasks.
- **DOM Manipulation:** Dynamically render tasks and update the interface.
- **Event Handling:** Handle clicks and user interactions.
- **Template Literals:** Generate HTML dynamically.
- **Conditional Rendering:** Change task styles and icons based on completion status.
- **CRUD Operations:** Create, read, update, and delete tasks.
- **Local Storage:** Persist task data using `JSON.stringify()` and `JSON.parse()`.
